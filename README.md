Обычный едд блокер хз

Установка: 
Скачайте файлы из репозитория.
Откройте браузер на движке Chromium (пример: Chrome, Edge, Opera, Brave).
Перейдите в настройки браузера и откройте вкладку «Расширения».
Включите режим разработчика.
Нажмите «Загрузить распакованное расширение».
Выберите папку с файлами, скачанными из репозитория.
В настройках расширений включите расширение Ad Block Pro
После этого расширение будет готово к использованию и начнет работать.

Код сделан по рофлу некоторые рекламы могут не блокироваться
